
# Fase 2: Planificación y diseño

## Objetivo

Mejorar mi portafolio digital de GitHub conservando la presentación original y mi estilo personal, incorporando información de los proyectos y tecnologías utilizadas durante el curso.

## Estructura propuesta

1. Presentación personal
2. Tecnologías y habilidades
3. Proyectos destacados
4. Tecnologías aplicadas en los proyectos
5. Contacto

## Decisiones de diseño

- Conservar la presentación original en inglés.
- Mantener los emojis y el estilo sencillo del README.
- Utilizar Markdown para organizar la información.
- Agregar tres proyectos académicos.
- Incluir enlaces directos a los repositorios.
- Evitar información personal sensible.
- Mantener una lectura clara en dispositivos móviles.

## Estrategia de commits

Los cambios se realizarán de manera incremental:

1. docs: agrega planificación del portafolio
2. docs: organiza habilidades y tecnologías
3. feat: incorpora proyectos destacados
4. docs: describe tecnologías aplicadas
5. fix: revisa formato y enlaces del portafolio

## Criterio de conservación

El contenido original del README se mantendrá como base. Las modificaciones se enfocarán en agregar información necesaria para cumplir los requisitos académicos, evitando eliminar elementos que forman parte de mi identidad digital.


## Fichas de proyectos destacados

### Proyecto 1: Esta es por Fiore

**Problema o necesidad:**
Dar visibilidad a una actividad deportiva solidaria y documentar las experiencias de sus participantes.

**Tecnologías utilizadas:**
HTML, CSS, Markdown y GitHub Pages.

**Funcionalidades principales:**
- Presentación de la actividad y su propósito.
- Sección de testimonios de participantes.
- Galería de fotografías.
- Información del evento y aprendizajes.
- Navegación entre secciones.

**Repositorio:**
https://github.com/Arihuz124/Proyecto-por-Fiore

**Demostración:**
https://arihuz124.github.io/Proyecto-por-Fiore/

### Proyecto 2: Organizador de Aula Virtual ESPOL

**Problema o necesidad:**
Facilitar la organización de materias y actividades pendientes dentro del aula virtual de ESPOL.

**Tecnologías utilizadas:**
JavaScript, CSS y herramientas de extensiones de navegador.

**Funcionalidades principales:**
- Visualización de materias activas.
- Filtros de actividades por materia.
- Personalización de colores.
- Ocultamiento de materias.
- Contador de actividades pendientes.

**Repositorio:**
https://github.com/Arihuz124/Extension-Canva-aula-virtual-ESPOL

**Demostración:**
Extensión instalable de manera local siguiendo las instrucciones del repositorio.

### Proyecto 3: Malla Interactiva ESPOL

**Problema o necesidad:**
Facilitar la visualización de la estructura curricular y el seguimiento de asignaturas aprobadas.

**Tecnologías utilizadas:**
React, TypeScript y Tailwind CSS.

**Funcionalidades principales:**
- Visualización de asignaturas por semestre.
- Marcado interactivo de materias aprobadas.
- Organización visual de la malla curricular.
- Adaptación de la interfaz a dispositivos móviles.

**Repositorio:**
https://github.com/Arihuz124/malla-interactiva-espol-main

**Créditos:**
Proyecto basado en el trabajo original de David Sánchez Romero, con modificaciones y mejoras propias.

## Selección de tecnologías

| Tecnología | Aplicación |

## Decisión final de diseño

Se conservará el texto original de presentación, los intereses personales y la sección de contacto.

Las nuevas secciones se incorporarán después de las habilidades existentes, manteniendo el idioma inglés y el estilo personal del README.

Los proyectos se describirán de manera breve, incluyendo tecnologías y enlaces funcionales, sin atribuirse trabajo realizado por otros desarrolladores.
