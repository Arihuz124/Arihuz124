## Conclusión del análisis

Los tres perfiles muestran distintas formas de presentar una identidad digital. Se observa que una presentación clara, una estructura organizada y la descripción de las habilidades permiten conocer rápidamente el perfil de un desarrollador.

Para mi portafolio se priorizará una presentación sencilla, con secciones de información académica, tecnologías, proyectos destacados y contacto. Cada proyecto incluirá una descripción, las herramientas utilizadas y un enlace a su repositorio.
